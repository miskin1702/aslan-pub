# Aslan - CloudStream 3 Eklenti Deposu

CloudStream 3 icin optimize edilmis Turkce film, dizi, canli TV ve spor yayin saglayicilari resmi dagitim deposudur.

## Kurulum (CloudStream 3)
1. CloudStream uygulamasini acin.
2. Ayarlar -> Eklentiler -> Depo Ekle bolumune gidin.
3. Asagidaki Depo URL'sini yapistirin ve kaydedin:
   ```
   https://raw.githubusercontent.com/miskin1702/aslan-pub/main/repo.json
   ```
4. Eklenti listesinden Aslan secip dilediginiz eklentileri yukleyin.

## Eklenti Listesi (14 Eklenti)
CanliTV, DiziMag, Dizipal, FilmMakinesi, FullHDFilmizlesene, Hdfilmcehennemi, InatBox, JetFilmizle, NetTV Gold, RecTV, SezonlukDizi, SporPaketi, WebteIzle, YabanciDizi.
